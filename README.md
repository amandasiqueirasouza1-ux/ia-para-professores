# IA para Professores

Recursos abertos em português para ajudar professores a usar inteligência artificial de forma prática, crítica e responsável.

Este projeto parte de uma regra simples: a IA pode apoiar o trabalho docente, mas a decisão pedagógica, a revisão do conteúdo e a responsabilidade final continuam sendo humanas.

## Para quem é

Professores do Ensino Fundamental que desejam experimentar IA no planejamento, na criação de atividades, na revisão de avaliações e na comunicação escolar sem expor dados de estudantes.

## Princípios do projeto

1. Não inserir dados identificáveis de estudantes em ferramentas públicas de IA.
2. Conferir fatos, cálculos, fontes, códigos e referências antes de usar qualquer resposta.
3. Adaptar o material à realidade da turma e às regras da escola ou rede.
4. Não usar detector automático como prova isolada de uso de IA.
5. Preservar a autonomia e a decisão profissional do professor.

## Como usar

Escolha um modelo, substitua os campos entre colchetes e revise a resposta antes de aplicá-la. Comece por uma atividade curta de um conteúdo que você já domina.

## Limites

Este projeto oferece material educativo. Ele não substitui orientação pedagógica, jurídica, institucional ou de proteção de dados. Cada escola ou rede pode possuir regras próprias sobre o uso de IA.

## Contribuições

Sugestões, correções e novos modelos são bem-vindos. Leia [CONTRIBUTING.md](CONTRIBUTING.md) antes de participar. Nunca envie exemplos que contenham dados pessoais de estudantes, responsáveis ou profissionais.
