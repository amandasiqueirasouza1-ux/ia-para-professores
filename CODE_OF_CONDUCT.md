# Código de conduta

Este projeto busca manter um ambiente respeitoso, acolhedor e profissional.

Não serão aceitos ataques pessoais, discriminação, assédio, exposição de dados, conteúdo ofensivo ou uso do projeto para identificar, classificar ou constranger estudantes e profissionais.

Discussões devem permanecer focadas no conteúdo, nas evidências e na melhoria dos recursos educacionais.
