# Roadmap

Este roadmap apresenta intenções de desenvolvimento, não promessas de prazo.

## Próxima versão

- revisar os materiais com professores de diferentes componentes curriculares;
- criar modelos de issue para correção, sugestão e novo recurso;
- ampliar exemplos de planejamento e avaliação;
- melhorar a orientação sobre acessibilidade;
- adicionar referências oficiais e data de revisão aos documentos;
- iniciar tradução revisada dos materiais essenciais para inglês.

## Etapa seguinte

- criar uma página estática simples para navegar pelos recursos;
- oferecer arquivos editáveis para impressão;
- documentar um processo seguro de teste com professores;
- receber e revisar as primeiras contribuições externas;
- estudar um verificador local de possíveis dados pessoais antes de contribuições.

## Fora do escopo atual

- coleta de dados de estudantes;
- correção automática com decisão final da IA;
- diagnóstico de aprendizagem;
- substituição de orientação institucional, pedagógica ou jurídica;
- promessa de resultados educacionais.
